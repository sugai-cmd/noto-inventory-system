# カナカン発注書FAXの受注取込

ブラザー複合機で受けたFAX（Gmailに `From_BrotherFAX` のPDF添付で届く）のうち、
**カナカンの発注書**を読み取って受注に登録します。OCRは無料のTesseractをMacの中で動かします。

## 1. 準備（最初の1回だけ）

```bash
brew install tesseract tesseract-lang poppler
tesseract --list-langs | grep jpn   # jpn と出ればOK
```

## 2. 使い方

Gmailから発注書のPDFを保存して、次を実行します。

```bash
# まず登録せずに中身だけ確認する
node scripts/import-fax-order.js --dry-run ~/Downloads/60000520261010100805_001.pdf

# 問題なければ登録する（複数ファイルもまとめて渡せる）
node scripts/import-fax-order.js ~/Downloads/*.pdf
```

| 表示 | 意味 |
|---|---|
| ✔ 受注 O2610-0001 を登録 | 登録しました |
| ○ 登録予定（--dry-run） | 登録内容の確認のみ |
| - スキップ（登録済み） | 同じ発注番号の受注がすでにある（取消済みも含む） |
| - カナカンの発注書ではない | 他社のFAX。何もしません |
| ⚠ 要確認（登録していません） | 理由と候補を表示します。受注画面から手で登録してください |

1件あたり数秒かかります。

## 3. 登録される内容

| 受注の項目 | FAXのどこから |
|---|---|
| 受注日 | 発注日 |
| 得意先 | 納入倉庫の名前（例「カナカン酒類石川」）と同じ名前の得意先。本店「カナカン」は選ばない |
| 商品 | JANコードで商品マスタから引く（商品名はFAXで崩れるため使わない） |
| 数量（本） | 入数 × 発注数量（例: 12X 1、2 C → 24本） |
| 納品希望日 | 入庫日 |
| 備考 | 先頭行に `カナカン発注番号：73068150`（二重登録の防止に使うので消さない） |

単価・掛率は通常の受注登録と同じく、商品の上代と得意先（支店が空欄なら本店）の掛率から入ります。
送料は0で入るので、必要なら受注画面で直してください。

## 4. 要確認になるとき

推測で登録はしません。次の場合は登録せずに理由を出します。

- 発注番号（8桁）・発注日・入庫日・入数／数量が読めない
- JANがチェックデジットで合わない、または商品マスタにない（→ 商品マスタのJANを確認）
- 納入倉庫の名前に当たる得意先が決まらない（→ 得意先マスタに支店があるか確認）

## 5. 仕組み

```
PDF → pdftoppm（300dpi画像）→ Tesseract（日本語）→ 項目の読み取り → マスタと突合 → 受注登録
```

- 罫線と同じ行の文字が崩れることがあるため、ページの読み方を変えて最大3回読み、
  項目ごとに読めた回の値を使います（`src/services/faxOrder/ocr.js`）。
- 読み取り: `src/services/faxOrder/kanakanParser.js` / 突合と登録: `src/services/faxOrderImportService.js`
- Tesseractの場所を変えたいときは `TESSERACT_BIN` / `PDFTOPPM_BIN` で指定できます。

## 6. まだできていないこと

- **Gmailからの自動取得**: いまはPDFを手で保存して渡す。Gmail API（OAuth）でアプリが
  `from:FromBrotherDevice@brother.com` を定期的に見て、この取込を呼ぶ形にする予定
  （COREZO注文メールの自動取込と同じ認証を使う）。
- 受注画面からPDFをアップロードして取り込むボタン
